# AppHero – Modern App Marketplace Interface

A modern, responsive web application showcasing a collection of productive mobile apps. AppHero serves as a sleek, user-friendly marketplace interface where users can browse, search, and manage application installations.

**🔗 Live Site:** [Visit AppHero](https://app-hero-dev.netlify.app/)

---

## ✨ Main Features

- **App Browsing** - Explore a curated collection of productive mobile apps
- **Search Functionality** - Quickly find apps by apps name
- **Installation Management** - Install and uninstall apps with real-time feedback
- **Data Visualization** - Interactive app review charts using Recharts
- **Responsive Design** - Optimized for all devices with modern UI components
- **Toast Notifications** - User feedback for app installation/uninstallation actions
- **Dynamic Routing** - Smooth navigation with React Router

---

## 🛠️ Technology Stack

- **Vite + React 19** - Modern development framework
- **Tailwind CSS v4 + DaisyUI** - Utility-first styling with component library
- **React Router** - Client-side routing
- **Axios** - HTTP client for data fetching
- **Recharts** - Data visualization for app reviews
- **React Icons** - Comprehensive icon library
- **React Toastify** - Toast notification system

## 🚀 Running Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/rahmanshaon/A08-hero-apps
   cd A08-hero-apps
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. **Open browser** at `http://localhost:5173`
